CSMA/CD

Collision Detection

Nodes listen to the shared channel before transmitting. If multiple nodes transmit simultaneously, a collision is detected and the nodes use binary exponential backoff before retransmitting.

Sense → Transmit → Detect Collision → Backoff

CSMA/CA

Collision Avoidance

Wireless nodes sense the channel and use a random backoff mechanism before transmitting. Successful transmission can be confirmed using acknowledgements.

Sense → Backoff → Transmit → ACK
